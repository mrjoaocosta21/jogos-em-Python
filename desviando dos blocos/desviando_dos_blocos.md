# Desviando dos Blocos

Este é um jogo simples desenvolvido em Python utilizando a biblioteca **Pygame**, onde o objetivo do jogador é desviar dos blocos que caem do topo da tela para acumular pontos.

---

## 📋 Pré-requisitos

Antes de rodar o jogo, você precisa ter o **Python** instalado no seu computador. Para verificar se ele já está instalado, abra o seu terminal (ou prompt de comando) e digite:

```bash
python --version
```

Caso não tenha o Python instalado, faça o download e a instalação através do site oficial: [python.org](https://www.python.org/).

---

## ⚙️ Instalação

O jogo utiliza a biblioteca `pygame` para gráficos e controle de teclado. Você pode instalá-la facilmente usando o gerenciador de pacotes `pip`.

Abra o terminal na pasta onde o arquivo `desviando_dos_blocos.py` está salvo e execute o comando:

```bash
pip install pygame
```

---

## 🚀 Como Executar o Jogo

1. Certifique-se de que o arquivo principal do jogo se chama `desviando_dos_blocos.py` e está salvo no diretório de sua preferência.
2. Abra o terminal na mesma pasta do arquivo.
3. Execute o script com o comando:

```bash
python desviando_dos_blocos.py
```

---

## 🕹️ Controles

* **Seta Esquerda ($\leftarrow$):** Move o jogador para a esquerda.
* **Seta Direita ($\rightarrow$):** Move o jogador para a direita.
* **Objetivo:** Desvie dos blocos vermelhos. Se você colidir com algum bloco, a pontuação é reiniciada do zero!
